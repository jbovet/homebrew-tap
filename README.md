# jbovet/tap

Homebrew formulae for [tlschecker](https://github.com/jbovet/tlschecker), a
TLS/SSL certificate checker: expiry, chain, revocation and grade.

## Install

```sh
brew install jbovet/tap/tlschecker
```

This installs the release binary for macOS or Linux (arm64 or x86_64), with
bash, zsh and fish completions. Installing by the full name also trusts the
formula, as Homebrew 6 requires for non-official taps.

To install by the short name instead, trust the formula first:

```sh
brew tap jbovet/tap
brew trust --formula jbovet/tap/tlschecker
brew install tlschecker
```

In a `Brewfile`:

```ruby
brew "jbovet/tap/tlschecker", trusted: true
```

## Updates

`brew upgrade tlschecker` picks up new releases. `Formula/tlschecker.rb` is
generated by tlschecker's release workflow, so don't edit it here: changes
belong in
[`.github/homebrew/formula.sh`](https://github.com/jbovet/tlschecker/blob/main/.github/homebrew/formula.sh).
