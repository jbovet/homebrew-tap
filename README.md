# Jbovet Tap

## How do I install these formulae?

`brew install jbovet/tap/<formula>`

Or `brew tap jbovet/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jbovet/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
